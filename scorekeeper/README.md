# Rinkside Scorekeeper Practice

An independent, mobile-friendly practice simulator for Burnaby minor hockey volunteer scorekeepers. Rehearse a fictional electronic scoresheet before game day, without touching any real game.

**Unofficial. Not affiliated with, sponsored, approved or endorsed by Spordle, PCAHA, BC Hockey, Burnaby Minor Hockey, the City of Burnaby or any manufacturer. This is not official training, certification or an official game record.** Use current official instructions and game officials for final guidance.

## Run locally

Open `scorekeeper/index.html` from the combined repository in a browser. It is a buildless HTML/CSS/JavaScript app. No account, database or application packages are needed. Everything is fictional and stays in the tab; closing or reloading resets the exercise. Do not enter real player data, credentials, signatures or team identifiers.

The app fills the viewport, with no branding header or disclaimer footer. **← Home** returns to the shared tool picker. The initial acknowledgement and **About** keep limitations and official-help links available. After demo login, the practice menu and coach collapse into a compact row so the scoresheet has more room. Expand the practice control to see Home, Choose practice, About and full guidance; collapse it again when ready. Help and mistake feedback remain accessible, and simulated sync stays available while compact. The scoresheet scrolls independently.

The sample team has 16 fictional players in total: 14 skaters plus two goalies. This is a practice roster, not a claim about league roster limits. Pregame attendance selections control which skaters appear in goal and penalty pickers. Phone actions are paired in two columns: Away on the left, Home on the right, with Goals, Penalties and Goalies aligned by row. Wider screens keep the official screenshot’s six-button mirrored row. The charcoal panels, dark-blue goal buttons, brighter-blue penalty/goalie buttons and green/gold/white player selections use colours sampled from the official guide screenshots; the simulator retains its own name and disclaimer.

Use **Full game simulation** or **Task walkthroughs** on the opening screen, or **Choose practice** at any time. The chooser groups the complete game separately from specific tasks, including pregame setup/lookup and End Game times, review and sign-off. The End Game exercise starts with the completed sample game sheet so you can rehearse the final steps without replaying the game. Assisted mode shows instructions. Unassisted mode shows events and offers Help. An incorrect saved answer explains what to fix and leaves the form open without changing the practice sheet. Help is also available inside entry dialogs and preserves the unfinished form. Opening Help during simulated sync preserves the completion control.

Use **Skip pregame setup → Start playing** on demo login or the pregame screen to fill all sample setup details in one click. It starts three 15-minute periods at 18:00 with Remaining Time and jumps full-game training to its opening goal. Partial pregame entries are replaced with the sample details. The normal setup remains available for practising it.

The full game contains pregame checks, three periods, goals and assists, a corrected scorer, a power-play penalty release, concurrent penalties, a carry-over penalty, a goalie change, period-length correction, bench penalty, optional shots/notes and final sign-off. Period lengths and game events are sample exercises, not league rules. There is no running arena clock or automatic penalty/manpower decision.

## Source references and fidelity

Primary visual reference: [PCAHA 2026–27 scorekeeper training video](https://pcaha.ca/wp-content/uploads/2026/09/2026-2027_PCAHA_Spordle_Scorekeepers_Training_FINAL.mp4), reviewed as extracted slide frames across its 8m41s duration. Audio was not transcribed. Relevant references include pregame/login around 1:15–2:30, goals around 3:30, penalties around 4:00, goalie changes around 5:00, corrections around 6:45 and wrap-up around 7:45–8:30.

Cross-reference: [official Spordle scorekeeper help](https://help.spordle.com/space/PLD/3489202177/Scorekeeper+guide) and [PCAHA manager resources](https://pcaha.ca/resources/team-managers/).

Review Game displays the full recorded sheet by period, including scorer/assists, penalty start/end and serving players, goalie changes, final/actual game times, lineups and shots by goalie/period.

The wrap-up now follows the written Spordle guide: final clock and actual start/end times, review with off-ice initials, game officials’ review/initials and Done, Submit, then sync and Finish. The supplied PCAHA video presents a different sequence. The simulator states this conflict rather than treating either source as proof of the current live app. Confirm the procedure used by your league. Simulated sync is advanced using a control outside the fictional app; no real submission occurs.

The pregame screen reminds scorekeepers that their team manager may already have completed the details: check and confirm them, and ask the manager to resolve missing or incorrect information. Start Game stays disabled until both rosters (players, bench staff and coach confirmation), Scorekeeper & Timekeeper, and Game Officials are complete. In Scorekeeper & Timekeeper, tap each pencil, search by name or HCR number, select an Official or Volunteer result, then Save. Finish both assignments with Done. Typing alone does not select a person. The lookup uses a fictional local directory: try Alex or DEMO-HCR-101 for an Official, and Sam for a Volunteer. It never searches real HCR records.

The Start Game wizard collects period lengths and actual start time, then offers Elapsed Time or Remaining Time with Previous and Start. Guided exercises use Remaining Time; free practice supports either choice. Previous preserves the entered values. Roster practice walks through players, bench staff and fictional coach confirmation. Actual PCAHA rosters remain the team manager’s responsibility. Game Officials supports name corrections, Did not show / Remove and a temporary fictional replacement. Pregame details can be revisited during free practice.

On phones, entry dialogs fill the screen, keep Help/Cancel fixed, and let the form scroll independently. Save/Next remain available while scrolling. Goal and penalty panels use the guide’s charcoal backgrounds, light time fields, green scorer, white assists/serving player and gold offender. The compact top toolbar provides labelled icons for Pregame, Shots, Notes, Options and End Game. Wide views show their text labels. The official wide-screen toolbar also shows Scoresheet, Timeout and Spectators; those extra workflows are not simulated. The icon-only phone presentation is a responsive adaptation, not a verified exact copy of the official mobile app.

Enter arena-clock readings as `3:00` or `03:00`. A visible **:** button beside each game-time field inserts the separator while using the numeric keyboard; tapping it again does not add a duplicate. The official guide uses colon-separated examples but does not document digits-only typing. This simulator does not assume that `300` or `3` is an official shortcut.

Active penalties appear as serving-player jerseys, grouped Away/Home so simultaneous penalties remain distinguishable. Tap a jersey to enter the confirmed end; penalty details show offender and serving player plus Edit and End. Ended penalties leave the active strip but stay in the historical sheet with an Edit end control. As in the reference’s unset display, unresolved entries show `Ends --:--`; this scoresheet has no live countdown or automatic release. Non-timed ejections are retained in the sheet without an active timed-service jersey.

Goalie controls use selectable mask icons with outgoing/incoming labels and Swap, Pull and Return. Away Goalie changes the away team’s goalie; Home Goalie changes the home team’s goalie. These actions record substitutions or an empty net, not goals or saves. Current goalie is recalculated from the timeline when an earlier change is edited or deleted. Shots are recorded against each goalie in each period and summed for the opposing shooting team. The guide counts shots, not saves. The PCAHA video’s alternative paper/Notes instruction remains linked. Only track shots when your league requires them.

The Major/Match walkthroughs explicitly practise time-first entry, following the video checklist; its regular-minor example uses a different order. The penalty form allows Off/Start clock readings to be entered before player and infraction selections, or afterwards; choosing an infraction preserves those readings. A separate Select Infraction screen offers the assessed types available for that infraction, then returns to the preserved penalty draft. Cancel and Escape return without applying selection changes. Penalty Start Time follows Off Time until manually changed. Ended penalties retain their end when edited; an edit that would place the start after the recorded end is rejected. Opportunities can be entered as 0–2 for these exercises. By-code and by-section search covers the minor-hockey rule headings in [Hockey Canada’s 2026–28 rulebook](https://www.hockeycanada.ca/en-ca/hockey-programs/officiating/downloads), not a complete proprietary regional Spordle code database. Slashing includes the official screenshot examples A22, B22 + D22 and B22 + E22, clearly labelled as guide examples rather than a verified current regional codebook. Junior/Senior-only choices are excluded. Major includes Game Misconduct, and Major/Match require a different serving skater. Dedicated exercises cover those selections. The referee supplies the assessment and release: this is not a penalty-rules or eligibility engine. Every regional code, combined charge, overtime/shootout scenario, real offline sync and live submission remain outside this simulator.

The screens, styling and implementation are original. No Spordle logos, proprietary source, screenshot assets, video footage or real rosters are included. Third-party names and linked materials belong to their owners. MIT applies only to the original project code; linked reference material is not relicensed.

Review Game supports Edit, Delete and Back. Corrections preserve final game times and invalidate sign-off. Returning from officials requires review and initials again. Guided corrections must retain the exercise’s expected records and do not advance its step. Participant buttons distinguish skaters, goalies, coaches and the bench using original CSS shapes.

See [the combined verification report](../VERIFICATION.md) for browser coverage, fixes, full-resolution official screenshot links and remaining scope limits.

## Tests

From the repository root: `node --test scorekeeper.test.cjs`

`node scorekeeper.browser.test.cjs` uses Playwright and installed Chrome. Set `PLAYWRIGHT_MODULE` to the module path if it is not installed normally. It serves this repository on loopback and tests all 11 scorekeeper scenarios on desktop and phone, each in assisted and unassisted modes (44 runs). Every run includes a wrong entry, Help while stuck, preservation of the form and successful correction. Unassisted runs request Help at every step, including final times and sync. Set SIMULATOR_BASE_URL to a published combined-site URL for the same tests against a deployment; SCOREKEEPER_VIEW=desktop or phone selects one half of the matrix. It also checks home/navigation and both clock models. `node scorekeeper-mobile-entry.browser.test.cjs` checks phone/tablet entry panels, toolbar actions, colours, colon entry, Help, serving-player icons and independent concurrent-penalty release. It also supports SIMULATOR_BASE_URL for live checks. `node scorekeeper-controls.browser.test.cjs` covers Major/Match entries, rule search, the editable Start Time, preserving penalty ends, historical goalie corrections, Pull/Return and no-show replacement on phone and desktop.

Both simulators are published together through the hockey-clock-simulator GitHub repository. It has no connection to VersaCloudERP, even when stored beside that checkout locally.
