How this practice differs

This practice follows the written Spordle guide for wrap-up: End Game times → Review Game and off-ice initials → Game Officials / Done → Submit → Sync / Finish. The PCAHA video presents a conflicting order, so confirm your current league’s procedure. The sign-off and sync here are fictional.

Shots are entered against each goalie in each period, as described in the written guide. The PCAHA video also recommends a scratch sheet and Notes when required; follow your league’s requested method. Rule-reference search uses Hockey Canada’s 2026–28 headings with Junior/Senior-only entries excluded. Slashing includes code examples from the official screenshots, labelled as guide examples. The complete current regional codebook, eligibility and every combined-penalty case are not reproduced. The referee supplies the assessment and opportunities; this tool does not decide them.
